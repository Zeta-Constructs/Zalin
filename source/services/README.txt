Service folder

The service folder should only contain systems that are:
    1. Too large to realistically be placed anywhere else.
    2. Important/Core Component to the entire system.
        2.1: Examples of this would be:
            2.1.1: Database manager
            2.1.2: Discord bot(?)
            2.1.3: Telemetry
            2.1.4: Tunnels (like the one here!)
